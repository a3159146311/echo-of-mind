# 心语 · 伦理红线

本文件由 Session 1 确立，修改需社区讨论。以下五条，任何 PR 不得违反：

1. **永不诊断。** 不使用"你有抑郁症""你需要吃药"等表述。我们描述感受，
   不命名疾病。专业判断只属于专业人士。
2. **危机干预不依赖概率模型。** 自伤/自杀信号的检测与响应由确定性代码
   （正则词库 + 人工撰写的话术）完成，LLM 永远不单独处理危机。
   一个 1.5B 的模型在生死关头幻觉一次，代价不可接受。
3. **数据永不离开设备。** 默认零遥测、零云同步、零分析埋点。
   用户的心事只存在于用户自己的硬盘上。
4. **永远亮明 AI 身份。** 不伪装成人类，不暗示"我懂你的痛苦"到
   僭越真实人际连接的程度。我们做桥梁，不做替身。
5. **词库变更需双人审核。** `safety/` 目录下危机词库的任何**删减**，
   必须两名维护者 review。增加可单人提交。宁可误报，不可漏报。
