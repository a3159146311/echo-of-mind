# 🌙 心语 · EchoOfMind

> 一个完全运行在你自己电脑上的 AI 陪伴伙伴。
> **对话不上传、日记加密、模型离线**——你的深夜心事，只属于你。

（此处放一张日记面板截图：情绪曲线 + 暖色界面）

## 为什么做这个

市面上的情绪 App：数据上云、广告画像、按月订阅。
心语的选择：**数据不出设备、模型免费离线、代码开源**。
它记得你说过的每一句话——但钥匙只在你手里。

## 特性

- 🕯️ **深夜对话**——暖色炉火界面，像朋友陪聊，不像诊所问诊
- 🔐 **加密日记**——Fernet + scrypt，落盘即密文，数据库被拷走也读不出一个字
- 📈 **情绪曲线**——纯手写 SVG，零外部依赖，看清自己的起伏
- 🤝 **温和转介**——持续沉重时轻声提示专业资源，24 小时最多一次，不轰炸
- 🛟 **危机守护**——检测到自伤风险立即响应，附 12356 心理援助热线
- ⚡ **全本地**——Qwen2.5-1.5B + llama.cpp，无需 GPU，无需联网

## 快速开始
bash
git clone https://github.com/YOUR_GITHUB_USERNAME/echo-of-mind.git
cd echo-of-mind
bash scripts/install.sh # 装依赖 + 下模型（约 1.1GB，一次性）
bash scripts/start.sh # 一键启动，浏览器自动打开

## 架构

浏览器(单文件HTML) → FastAPI(危机检测→LLM→情绪评分→温和转介)
↓ ↓
llama.cpp + Qwen2.5 Fernet 加密日记(SQLite)
(本机 8080 端口) 密钥仅存于进程内存

## 安全模型（诚实边界）

- 日记 AES 加密落盘，密钥由口令经 scrypt 派生，只存活于服务进程内存；
- 主动上锁 = 从内存抹除密钥；
- 已知弱点：首次启动自动生成口令存于 `backend/app/.diary_key`（权限 600）——请把它抄到纸上并考虑删除文件后等待后续版本的自设口令功能；同机 root 可读取内存中的密钥，单用户个人设备场景下可接受。
